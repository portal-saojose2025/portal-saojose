# 📖 Portal São José do Gorutuba

Este repositório contém o código-fonte do site do **Portal São José do Gorutuba**, com páginas sobre história, eventos, galeria, folias, doações, administração, patrocinadores e contato.  

---

## 📂 Estrutura do Projeto

```
/
├── index.html             → Página inicial
├── historia.html          → História do Gorutuba
├── eventos.html           → Eventos e celebrações
├── galeria.html           → Fotos e vídeos
├── folia.html             → Folias e foliões
├── adm.html               → Administração e equipes
├── patrocinadores.html    → Patrocinadores
├── doacoes.html           → Página de doações
├── contato.html           → Formulário de contato
├── /css
│   └── style.css          → Estilos (cores, fontes, layout)
├── /js
│   └── script.js          → Interações e animações
└── /assets
    ├── /img               → Fotos
    ├── /videos            → Vídeos
    └── manifest.json      → (opcional)
```

---

## 🚀 Como publicar no GitHub Pages (pelo celular)

1. Abra o **GitHub** no navegador do celular.  
2. Entre no seu repositório do site.  
3. Toque em **Add file → Upload files**.  
4. Envie os arquivos e pastas exatamente como estão listados acima.  
   - 📌 Se já existir, pode **substituir** (não precisa apagar manualmente).  
5. Depois vá em **⚙ Settings → Pages**.  
6. Em **Source**, escolha:  
   - **Deploy from a branch**  
   - **Branch: main**  
   - **/ (root)**  
7. Salve.  
8. Aguarde 1–2 minutos → o site vai abrir no link do GitHub Pages.

---

## 💡 Dicas

- Se abrir **página em branco**, confira se o nome do arquivo está correto (exemplo: `index.html`, não `Index.HTML`).  
- Fotos e vídeos devem ser colocados dentro da pasta `/assets/img` e `/assets/videos`.  
- Sempre atualize os arquivos direto pelo **Upload files**.
